# UI 排版修正 & 音乐库详情弹窗设计

日期: 2026-05-08

## 背景

Music Studio 的音乐生成表单中，多个选项文字在窄容器中折行显示不美观。音乐库缺少查看歌曲风格描述和歌词的功能。

## 需求

### 1. UI 排版修正

将以下选项组从水平排列改为垂直排列，每个选项独占一行：

- 器乐（无人声）/ 自动优化歌词 — 两个 checkbox
- 输出格式 Hex / URL — 两个 radio
- 添加 AIGC 水印 — 单个 checkbox（已 full-width，无需改动）

### 2. 音乐库详情查看

- 新建 `DetailModal.svelte` 只读弹窗，展示风格描述（prompt）和歌词（lyrics）
- 在 MusicCard 操作栏增加「详情」按钮触发弹窗
- 歌词仅在非器乐歌曲时展示；器乐曲显示「器乐曲，无歌词」提示
- 风格描述所有音乐都展示

## 修改文件

| 文件 | 改动 |
|------|------|
| `MusicForm.svelte` | `.form-row` 改为 `flex-direction: column`，去掉 `flex-wrap: wrap` |
| `MusicCard.svelte` | 扩展 music 类型（添加 prompt、lyrics）；操作栏增加「详情」按钮；引入 DetailModal |
| 新建 `DetailModal.svelte` | 只读弹窗，展示风格描述和歌词 |
| `zh.ts` / `en.ts` | 添加详情相关 i18n 文本 |

## 数据流

- `MusicRecord` 已包含 `prompt` 和 `lyrics` 字段，前端 MusicCard 接收的 music 对象只需扩展类型声明
- 无需后端改动，无需额外 API 调用
