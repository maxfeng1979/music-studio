## Page Structure

```
写作页 (WritePage)
    ↓ [提交]
结果页 (ResultPage)
    ↓ [返回]
写作页 (WritePage)

[导航栏按钮]
    ↓
设置页 (SettingsPage)
    历史/收藏 → 通过 MD 导出到本地目录，由 Obsidian/Notion 等工具管理
```

MVP 共 2 个核心页面 + 1 个设置页。

---

## Page 1: 写作页 (WritePage)

### Layout
单列沉浸式，全屏一个文本框，无侧边栏，无干扰。标题居中，按钮居中，布局加宽。

### Components

| 组件 | 描述 |
|------|------|
| 导航栏 | 中：App名称 "LinguaLog"（居中）/ 右：历史📁、设置⚙️ 按钮 |
| 语言选择 | 两个下拉选择器：日记语言 → 目标语言，均支持 8 种语言 |
| 文本框 | 占满中间区域，最小高度 260px，支持多行 |
| 提交按钮 | 居中蓝色按钮，文字"提交 →" |

### Language Support

**支持语言（日记语言 + 目标语言均相同）**：
- 中文（中文）
- English（英文）
- Français（法文）
- Italiano（意大利文）
- Español（西班牙文）
- Deutsch（德文）
- 日本語（日文）
- 한국어（韩文）

默认：日记语言=中文，目标语言=English。

### Mode Behavior

**日记语言模式（默认）**：
- 用户用选定日记语言写日记
- 提交后 → AI 整理（保持原意，修正不完整/不规范表述）→ AI 翻译为选定目标语言 → 跳转结果页

**目标语言模式**：
- 用户直接用目标语言写
- 提交后 → AI 润色（保持原意，使表达更地道）→ 跳转结果页

### Interactions
- 模式切换即时生效，不保存状态，下次打开默认日记语言
- 文本框 placeholder："写下今天发生的事情..."
- 提交按钮点击后进入 loading 状态，提交成功后跳转

## Page 2: 结果页 (ResultPage)

### Layout
日记提交后的学习页面。双栏卡片堆叠，每段一行，按顺序从上往下排列。

### Page Header
- 显示日记日期
- 右侧：全局「遮盖翻译」toggle（默认关闭）
- 左上角：「返回」按钮回到写作页

### Card Structure

每段一张卡片，结构如下：

```
┌─────────────────────────────────────────────────┐
│  🔊男  🔊女  ⭐收藏      [遮盖 toggle]          │  ← 工具栏（内容上方）
├────────────────────────┬────────────────────────┤
│  原文                   │  [目标语言名称]         │  ← 标签（动态）
│  [原文句子]             │  [翻译句子]             │  ← 内容
│                         │  （磨砂遮盖时可隐藏）    │
│  润色后                 │                        │
│  [润色原文]             │                        │
└────────────────────────┴────────────────────────┘
```

- **左栏**：原文 + AI 润色后的原文（上下排列）
- **右栏**：目标语言翻译（标签动态显示用户选定的目标语言名称）
- **工具栏**：在内容上方（紧贴翻译），顺序为：🔊男声、🔊女声、⭐收藏、遮盖toggle
- **遮盖效果**：磨砂玻璃（`backdrop-filter: blur(6px)`）+ 白色半透明遮罩 + 文字 `filter: blur(4px)`
- **单卡遮盖**：每个卡片独立的遮盖 toggle，可单独控制

### Word Selection Popup
- 在任意翻译文本上选中文本（单词或词组）→ 紧贴选区下方弹出气泡
- 气泡内容：单词 + 音标 + 释义 + 🔊发音 + ⭐收藏
- 气泡有小三角指向词语
- 点击气泡外区域自动关闭
- 多词词组作为整体查询

## Page 3: 设置页 (SettingsPage)

### Sections

**1. AI 配置**
- Provider 选择：OpenAI 格式 / Anthropic 格式
- API Endpoint URL（用户填写，如 `https://api.openai.com/v1/chat/completions`）
- API Key（密码输入框，用户填写自己的 Key）
- 模型名称（默认填充，可自定义）
- 测试连接按钮

**2. TTS 配置**
- Provider 选择：内置服务（付费）/ 自定义
- 自定义：阿里云 TTS / 腾讯云 TTS / 其他（OpenAI 兼容格式）
- Endpoint + API Key + AppKey 等参数
- 测试朗读按钮

**3. 导出设置**
- MD 导出目录（文件夹选择器，默认 `~/Documents/LinguaLog/`）
- 导出文件名格式：`diary-YYYY-MM-DD.md`
- 导出内容格式：
  ```markdown
  # 日记：YYYY-MM-DD
  日记语言 → 目标语言

  ## 原文
  [日记原文内容]

  ## 润色后
  [AI润色后的原文]

  ## 翻译（[目标语言]）
  [AI翻译的目标语言]

  ## 收藏
  - 句子收藏...
  - 单词收藏...
  ```

**4. 外观（后续迭代）**
- 文本字体选择
- 日记背景主题
- 深色/浅色模式

## Visual Design

### MVP 风格：极简白
- 主色：#3B82F6（蓝）、#FFFFFF（白）、#F9FAFB（背景灰）
- 文字：#1F2937（标题）、#374151（正文）、#9CA3AF（辅助灰）
- 边框：#E5E7EB
- 圆角：12px（卡片）、8px（按钮）
- 磨砂遮盖：`backdrop-filter: blur(6px)` + 白色70%透明

### 后续迭代项
- 自定义文本字体
- 自定义日记背景
- 深色模式

## Interactions Summary

| 交互 | 行为 |
|------|------|
| 提交日记 | 跳转结果页，展示分段卡片 |
| 全局遮盖 toggle | 一键遮盖/显示所有翻译 |
| 单卡遮盖 toggle | 单独控制每个卡片的遮盖 |
| 选中文本 | 弹出释义气泡 |
| TTS 男声/女声按钮 | 播放对应语音 |
| 收藏按钮 | 收藏当前句子到 MD 文件 |
| 返回按钮 | 回到写作页 |
| 设置按钮 | 打开设置页 |

## Tech Notes

- 前端框架：React + TypeScript
- 状态管理：React Context 或 Zustand（轻量）
- 文本选中：原生 Selection API
- TTS：Web Speech API（浏览器内置，降级方案）+ 自定义 API 配置
- MD 导出：Node.js `fs` 模块，通过 Tauri Rust 后端写文件
- AI 调用：通过 Tauri HTTP 插件调用用户配置的 API 端点
