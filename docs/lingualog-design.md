# Design: LinguaLog — 语言习得日记应用

Generated by /office-hours on 2026-04-18
Status: DRAFT
Mode: Startup

## Problem Statement

英语学习材料（教材、课程）都是别人编写的内容，离用户真实生活很远。学出来的东西不实用，动机也难以持续。用户心里想说的话，不知道怎么用地道的英语表达。

## Demand Evidence

网上有大量视频和讨论在传播两种日记学习英语的方法：
1. 用现有水平写日记 → AI 纠正 → 对比差异
2. 心里想中文 → AI 翻译成地道英语 → 背诵实践

两种方法都有数百条评论、数千点赞收藏。尚未发现专门实现这些方法的 App。所有用户目前都是手动拼凑 ChatGPT + 笔记本来操作。

## Status Quo

用户目前的工作流：
- 在纸质日记本或笔记软件里写日记
- 把日记内容复制到 ChatGPT 对话框
- 手动对比 AI 纠错和原始内容的差异
- 手动收藏生词（复制到笔记或其他地方）
- 想听发音需要额外打开 TTS 工具

这个流程有 friction，每个环节都在打断用户的思路。

## Target User & Narrowest Wedge

**主要用户：** 职场人士，有实际使用英语的场景（邮件、会议、文档），有付费能力，有持续学习英语的动机。

**核心价值：** 每天积累自己生活场景中的地道英语表达，形成个人语料库。隐私保护（本地存储）+ AI 辅助纠错 + 词汇复习。

## Constraints

- **桌面端**：日记需要隐私，数据存在本地
- **Tauri + WebView**：轻量安装包，快速启动，原生体验
- **AI 通过外部 API 调用**：日记本地存储，调用外部 LLM 进行纠错/翻译，TTS 使用外部服务
- **MVP 阶段不设付费模块**：先验证产品，再考虑变现

## Premises

1. **日记 + AI 纠错** 这个方法对真实用户有效，不只是网上流传的概念 — agree/disagree?
2. **桌面端是正确发布形态** — 用户愿意在电脑上专门花时间写日记练英语，而不是在手机上碎片化操作 — agree/disagree?
3. **用户会持续使用** — 日记习惯本身有粘性，积累的语料库会成为留存理由 — agree/disagree?

## Approaches Considered

### Approach A: Tauri Desktop + 本地数据库 + 外部 AI API（推荐）
- 安装包小（~10MB），启动快
- 前端用 React/HTML+JS，后端用 Rust
- 日记数据存储在本地 SQLite
- AI 纠错/翻译调用 OpenAI/Claude 等外部 API
- TTS 调用外部服务（可选 Web Speech API 降级）
- MVP 纯免费，无账号系统，无付费模块

### Approach B: Web App（SaaS）
- 跨平台，数据存云端
- 隐私性弱，用户可能不愿把日记内容上传到第三方服务器
- 开发和部署更简单，但需要后端服务

## Recommended Approach

**Approach A: Tauri Desktop + 本地数据库 + 外部 AI API**

理由：
1. 隐私是产品的核心承诺之一，本地存储是最低成本的实现
2. Tauri 安装包小，下载摩擦低
3. 前端技术栈（React/JS）对 AI 工具调用友好
4. 无需维护服务器，MVP 阶段运营成本最低

## Core Flow

```
用户打开应用
    ↓
选择记录语言模式（单选，默认：源语言 / 目标语言）
    ↓
在文本框输入内容
    ↓
点击提交
    ↓
┌─────────────────────────────────────┐
│ 源语言模式（默认）：                  │
│   用户用源语言写日记                  │
│   → AI 整理句子（保持原意，修正不完整/│
│     不规范的表述，但不改写内容）       │
│   → AI 翻译成地道的目标语言           │
│   → TTS 合成语音（男/女声）          │
│   → 展示：原文 + 整理版 + 翻译版     │
│   → 可收藏：句子/单词/词组           │
│   → 点击单词/词组 → 弹释义           │
│                                      │
│ 目标语言模式：                       │
│   用户直接输入目标语言（英语）         │
│   → AI 检查并润色句子（保持原意）    │
│   → TTS 合成语音（男/女声）          │
│   → 可收藏：句子/单词/词组           │
│   → 点击单词/词组 → 弹释义           │
└─────────────────────────────────────┘
```

### AI 接口设计

**系统提示词（源语言模式）：**
> You are an English learning assistant. The user writes diary entries in [source language]. Your task:
> 1. Organize each sentence: fix incomplete or informal phrasing while keeping the original meaning intact
> 2. Translate to natural, fluent [target language]
> 3. Return structured JSON: { entries: [{ original, organized, translated }] }

**系统提示词（目标语言模式）：**
> You are a writing coach. The user writes in [target language]. Your task:
> 1. Polish each sentence to be more natural while preserving original meaning
> 2. Return structured JSON: { entries: [{ original, polished }] }

**输出格式：** JSON，字段为 `entries` 数组，每项包含原始句、整理后句、翻译句（如适用）。

**单词释义数据源：** LLM 即时生成（附加 disclaimer：AI 释义仅供参考，以词典为准）。后续可接入词典 API 替代。

**支持语言（源语言 + 目标语言均相同）**：中文、English、Français、Italiano、Español、Deutsch、、日本語、한국어。默认：源语言=中文，目标语言=English。

### 模式切换

语言模式为**单次切换**，不是全局设置。每次打开应用默认为源语言模式，用户可随时切换。

## Key Features

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 双语记录模式 | 源语言模式 + 目标语言模式切换（默认源语言） | P0 |
| AI 句子整理（源语言模式） | 整理不完整/不规范句子，保持原意 | P0 |
| AI 翻译 | 翻译成地道目标语言 | P0 |

| TTS 语音 | 男声/女声可选，发音按钮（Tauri + Web Speech API） | P1 |

## Open Questions

- TTS 优先用 Web Speech API（P1 阶段），外部付费 TTS API 作为未来选项
- 收藏内容的复习功能：简单浏览列表还是间隔重复？待 MVP 后根据用户反馈决定
- 数据导出功能（用户离开时的数据所有权）
- SQLite 加密：MVP 阶段先不加，用文件系统权限保护；后续按需引入 SQLCipher

### TTS 服务选项

| 服务 | 类型 | 说明 |
|------|------|------|
| Web Speech API | 免费内置 | 浏览器内置，无需配置，质量一般 |
| 阿里云 TTS | 自定义（付费） | 需配置 API Key、AppKey |
| 腾讯云 TTS | 自定义（付费） | 需配置 API Key、AppId |
| OpenAI 兼容端点 | 自定义 | 支持标准 TTS API 格式 |

MVP 阶段默认 Web Speech API，自定义 TTS 作为进阶选项。

## Success Criteria

- 用户能完成一次完整的日记提交 → AI 整理/翻译 → 收藏生词的流程
- 日记数据在本地持久化，重启应用后数据保留
- TTS 语音正常播放（Web Speech API，P1）
- 词汇收藏和搜索功能可用

## Distribution Plan

- 直接发布 Tauri 安装包（.exe for Windows）
- 用户下载即用，无需安装运行时
- AI API Key 由用户自行配置（用户用自己的 API 账号），无服务器成本
- MVP 纯免费，无账号系统

## Dependencies

- **框架**: Tauri 2.x
- **前端**: React（单选，TypeScript）
- **本地存储**: SQLite（SQLite 官方 Rust 绑定）
- **AI 调用**: OpenAI SDK / Anthropic SDK（支持多后端配置）
- **TTS**: Web Speech API（浏览器内置，免费）+ Tauri TTS 插件
- **加密**: MVP 阶段先用文件系统权限保护；SQLCipher 作为后续可选升级
- **构建**: Rust 工具链 + Node.js
